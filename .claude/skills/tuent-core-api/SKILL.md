# Tuent Core — tra API

Framework embedded: `Assets/TuentCore/`.

| Cần | Dùng |
|---|---|
| Log | `TLogger` (`Tuent.Core`) |
| Singleton Mono | `MonoSingleton<T>` |
| Pool | `TPool`, `TPoolers` |
| UI | `UIScreen`, `UIPopup`, `ScreenData`, `PopupData` |
| Signal | `Signal`, `BaseSignal` |

Code game → `Assets/_MainProject/Scripts/`, namespace riêng. Không `Tuent.Core*` cho type game.
